# 크리스마스 트리 영상 만들기 — 사용법

`index.html` 파일 하나로 동작합니다. 따로 설치할 프로그램은 없습니다. **최신 Chrome**에서 GitHub Pages 주소(`https://<아이디>.github.io/christmas-tree-studio/`)로 접속하거나, 내려받은 `index.html`을 직접 여세요. 인터넷 연결이 있어야 영상 인코더를 불러옵니다.

> 입력한 데이터와 토큰은 접속한 브라우저에만 저장됩니다. 다른 PC에서 열면 처음부터 입력해야 하고, 다른 사람에게 주소를 알려 줘도 내 데이터는 보이지 않습니다.

## 매일 할 일

### 수작업으로 할 때
1. 스튜디오 페이지를 Chrome으로 엽니다. 같은 브라우저라면 어제 입력한 값이 그대로 남아 있습니다.
2. 인스타 게시물에서 오늘 확인한 내용을 2번 칸에 입력합니다.
   - **좋아요 수**를 새 숫자로 고칩니다.
   - 새로 댓글 단 **계정명**을 목록 **맨 아래에** 한 줄씩 추가합니다. `@`는 붙여도 되고 안 붙여도 됩니다.
   - 같은 이름이 두 번 들어가면 자동으로 하나만 남고, 영문·숫자·`.`·`_`가 아닌 줄은 무시됩니다.
3. 3번 칸의 **기준일 표시**를 고칩니다. 예: `12월 1일 기준`
4. **[미리보기에 적용]**을 눌러 확인한 뒤, **[영상 만들기]**를 누릅니다.
5. 진행률이 100%가 되면 `tree-2026-12-01.mp4` 같은 이름으로 다운로드됩니다. 30초 영상 기준 1분 안팎 걸립니다. 이 파일을 미디어보드 CMS에 올리세요.

### API로 할 때
1번 칸에 토큰과 미디어 ID를 한 번만 넣어 두면, 매일 **[인스타 데이터 불러오기]** → **[영상 만들기]** 두 번만 누르면 됩니다.

## 영상 내용
- **크기와 길이**: 1080×1920 세로 MP4입니다. 기본 30초 동안 트리가 **천천히 한 바퀴** 돌고, 끝과 시작이 이어져 반복 재생해도 끊김이 없습니다.
  - 더 천천히 돌리려면 3번 칸의 "한 바퀴 = 영상 길이"를 늘리세요. 예: 45초
- **가지**: 댓글 단 계정 1개당 가지 1개가 그 이름의 글자로 채워지며 켜집니다. 빈 가지는 어두운 `*`로 남습니다.
- **입체감**: 앞쪽 가지는 크고 밝게, 뒤쪽 가지는 작고 어둡게 보입니다. 계정명 라벨은 정면을 향한 가지에만 나타납니다.
- **장식 전구와 별**: 좋아요 수 ÷ 목표 비율만큼 전구가 켜지고, 목표에 도달하면 꼭대기 별이 빛줄기와 함께 완전히 켜집니다.
- **스포트라이트**: 가장 최근 참여자 5명은 자기 가지가 정면으로 돌아올 때 이름이 크게 떠오릅니다.
- **가지 수**: 이름이 240명을 넘으면 가지 수가 자동으로 늘어납니다. 이때 트리 배치가 한 번 달라집니다.

## 인스타그램 API 연동 (선택, 무료)
Instagram Graph API는 **무료**입니다. 시간당 호출 수 제한만 있고, 하루 한 번 불러오기에는 전혀 문제없습니다. 다만 처음 설정이 번거로우니, 이벤트 규모가 작으면 수작업도 충분합니다.

API로 받을 수 있는 정보는 **좋아요 수**와 **댓글 단 계정명**뿐입니다. 좋아요를 누른 사람 목록은 받을 수 없습니다.

1. 인스타 계정을 **비즈니스 또는 크리에이터 계정**으로 전환하고, Facebook 페이지에 연결합니다.
2. [Meta for Developers](https://developers.facebook.com/)에서 앱을 만들고 Instagram Graph API를 추가합니다.
3. Graph API 탐색기에서 다음 권한으로 토큰을 발급받은 뒤, **장기 토큰(60일)**으로 교환합니다.
   - `instagram_basic`
   - `instagram_manage_comments`
   - `pages_show_list`
   - `pages_read_engagement`
4. **미디어 ID 찾기**: 탐색기에서 `GET /{인스타 비즈니스 계정 ID}/media?fields=id,caption,permalink`를 실행해 홍보 영상 게시물의 `id`를 복사합니다.
5. 토큰과 미디어 ID를 스튜디오 1번 칸에 붙여 넣습니다.
   - 토큰은 이 PC의 브라우저에만 저장됩니다.
   - "Instagram 로그인" 방식으로 발급한 토큰(`IG…`로 시작)을 쓴다면 API 주소를 `https://graph.instagram.com/v21.0`으로 바꾸세요.

## 참고
- **영상이 WebM으로 저장될 때**: 인터넷이 끊겨 인코더를 못 불러오면 실시간 녹화 방식으로 바뀝니다. 이 경우 WebM으로 저장될 수 있으니, 인터넷이 되는 상태에서 다시 만드세요.
- **개인정보**: 게시물에 "댓글을 남기면 계정명이 매장 미디어보드 트리에 표시됩니다" 같은 안내를 넣어 두기를 권장합니다.
